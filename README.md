One server, two wires: it serves the OpenAI Chat Completions API and the Anthropic Messages API (JSON and streaming) by routing each request to the best free model that meets its requirements, across ten simulated free-tier providers, failing over when a provider refuses.

## Run it

```sh
node main.ts
```
